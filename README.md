# Laundry Tag Printer: releases

Windows installers for Gaurav Dry Cleaners' Laundry Tag Printer.

Installed copies check this page for new versions and update themselves.
To install on a new PC, download the latest `Laundry-Tag-Printer-Setup-<version>.exe`
from **Releases** and run it.

This repository holds only installers; the source code is private.
